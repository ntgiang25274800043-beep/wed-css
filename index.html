WEB DESIGN

Khám phá CSS

CSS là ngôn ngữ giúp tạo kiểu và thiết kế giao diện cho các trang web trở nên đẹp mắt, hiện đại và chuyên nghiệp.

Tìm hiểu ngay
<style>

body {

color: #2563eb;

font-size: 20px;

}

</style>

CSS là gì?

CSS (Cascading Style Sheets) là ngôn ngữ dùng để định dạng và thiết kế giao diện cho trang web. CSS giúp kiểm soát màu sắc, font chữ, kích thước, bố cục và nhiều hiệu ứng khác.

🎨

Thiết kế

Thay đổi màu sắc, font chữ, nền và giao diện của website.

📐

Bố cục

Sắp xếp các thành phần trên trang bằng Flexbox và Grid.

📱

Responsive

Giúp website hiển thị tốt trên máy tính, điện thoại và tablet.

WHY CSS?

Tại sao nên học CSS?

CSS là một trong những kiến thức nền tảng quan trọng đối với lập trình web. Khi kết hợp HTML và CSS, bạn có thể tạo ra những trang web có giao diện chuyên nghiệp.

✓ Dễ học và dễ sử dụng
✓ Tạo giao diện đẹp mắt
✓ Hỗ trợ thiết kế responsive
✓ Hoạt động trên mọi trình duyệt hiện đại

Ví dụ CSS cơ bản

h1 {
    color: blue;
    font-size: 40px;
    text-align: center;
}
